# lr2ir-ghost-dataset
Roughly Scrabed ghost(replay) Data

lr2ir_ghosts.tar.gz: Total 4,166,362 records, which cover about 16% of total LR2IR ghost datas, datas that only be scrabed by me.

lr2ir_ghosts_extended.tar.gz: Total 5,120,190 records, which cover about 20% of total LR2IR ghost datas, merged with data of [zkldi/lr2ir-dataset](https://github.com/zkldi/lr2ir-dataset)

Sadly, I **randomly** scrabed datas, so lots of charts don't have all ghost datas.

Also, there are some archived pages of latest bmsids.

This dataset will be updated.
